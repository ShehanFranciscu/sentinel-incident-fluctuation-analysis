# Security and data handling

This repository is a **sanitized reference implementation** only. All supplied sample customer names, incident figures, and workspace IDs are fictional. It is not intended to contain live telemetry, customer data, authentication secrets, or production configuration.

Before creating issues or pull requests, remove customer identifiers, incident details, tenant/workspace/subscription IDs, tokens, client secrets, and potentially sensitive screenshots. Do not post suspected secrets or unredacted customer data in public issues. If you discover an accidental disclosure in this repository, contact the maintainer privately using a non-public channel and rotate any compromised credentials. Removing a file from the latest commit does not remove it from Git history.

Use `python3 scripts/public_release_check.py` for a preliminary check, but do not rely on it as a replacement for human review or provider secret scanning.
